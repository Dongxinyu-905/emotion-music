算法说明

系统由「本地情绪识别」与「情绪驱动推荐」两个算法模块组成，全部推理在浏览器内完成， 人脸画面不会上传到任何服务器。

输入(图片/视频帧/摄像头帧) → 人脸检测 → 68 关键点 → ① CNN 表情分类 + ② 几何规则引擎 → 融合 + 时序平滑 → 情绪分布与置信度 → 情绪原型 → 声学目标向量 → 候选曲库打分 → MMR 重排 → 歌单

一、情绪识别算法（全本地）

1. 人脸检测：TinyFaceDetector（SSD-MobileNet 轻量化结构），输入 416×416， 置信度阈值 0.32，一次前向可检出多张人脸并回归边界框。

1.5 多尺度补检：TinyFaceDetector 对占画面 80% 以上的正脸特写容易漏检。 若原始尺寸 0 检出，则把画面居中放入 1.8×、2.6× 的留白画布（降低人脸相对尺寸）重试， 再把框与关键点坐标逆变换回原图，取第一个有脸的结果。

2. 关键点回归：68 点人脸关键点模型，输出眉、眼、鼻、唇、下颌轮廓坐标， 用于几何层计算与界面可视化。

3. CNN 表情分类（主判据）：FaceExpressionNet，轻量卷积网络， 在 FER+ / AffectNet 类人脸表情数据上训练，输出 7 类 softmax 概率 （neutral / happy / sad / angry / fearful / disgusted / surprised）。 权重为 uint8 量化，约 3.4 MB，随项目放在 /models 目录，完全离线加载。

4. 几何规则引擎（辅助/降级）：以瞳距归一化，计算 7 个尺度不变的几何量， 再与 7 个情绪原型做高斯核匹配，softmax 得到分布：

mouthOpen = ‖p62 − p66‖ / d 张口度（AU26）
mouthWide = ‖p48 − p54‖ / d 唇宽（AU12 横向）
cornerUp = (y51 − (y48+y54)/2) / d 嘴角上扬（AU12）
browRaise = (ȳeyeTop − ȳ19,24) / d 眉眼距（AU1+2）
innerBrow = (ȳeyeTop − ȳ21,22) / d 眉心上抬（AU1+2 内侧）
eyeOpen = (EAR_left + EAR_right) / 2 眼睛开合（AU5）
mouthRound = mouthOpen / mouthWide 唇形圆度（MAR，惊讶时嘴变圆）

sc = − Σk wk · ((fk − μc,k) / σk)²　， Pgeo(c) = softmax(sc / T)，T = 2.6

5. 双层融合（CNN 可用时，权重自适应）：

wgeo = 0.10 + 0.30 · (1 − max PCNN)　　（CNN 越不确定，几何层话语权越大）
若 max Pgeo > 0.93 则 wgeo ≥ 0.38，且 wgeo ≤ 0.42　（强动作单元证据）
P = normalize( (1 − wgeo) · PCNN + wgeo · Pgeo )
consistency = 1 − ½·Σc |PCNN(c) − Pgeo(c)|　（层级一致性，用于界面提示与置信度加权）

6. 时序平滑与置信度：视频/摄像头按约 100 ms 采样一帧，对每个人脸位置做指数滑动平均 （α = 0.45）；置信度与稳定度：

P̄t = (1−α)·P̄t−1 + α·Pt
conf = 0.58·norm(max P̄) + 0.22·detScore + 0.20·consistency
streak = 连续同一情绪帧数（≥3 帧才触发换歌单；另有 stability = 最近 24 帧一致占比，用于界面显示）

7. 情绪坐标：由 7 类概率加权得到效价与唤醒度 V = Σpᵢ·vᵢ、A = Σpᵢ·aᵢ（Russell 环形模型），作为推荐的中间表示。

二、歌曲推荐算法

1. 情绪 → 声学目标向量：把情绪映射到 5 维可计算特征空间。

平静0.500.420.500.6090

2. 三种调节策略：共情（T = 原型）、疗愈（T = 原型 ⊕ 向上情绪，λ=0.62）、 提振（T = 原型 ⊕ 高能原型，λ=0.58）。

3. 打分函数（每首候选曲，权重和为 1）：

closeness = 1 − Σ wᵢ·|fᵢ − tᵢ| / Σ wᵢ　　w = (energy 1.15, valence 1.50, dance 0.95, acoustic 0.70, tempo 0.85)
valFit = exp(−(fv−tv)² / (2·0.24²))
moodMatch= exp(−d²circ / (2·0.46²))，dcirc = ‖(V,A) − (V*,A*)‖
affinity = 1 − Σ|fᵢ − prefᵢ| / 5　（用户偏好向量）
tempoFit = exp(−(ln(fbpm/tbpm))² / (2·0.26²))

score = 0.42·closeness + 0.18·valFit + 0.16·moodMatch + 0.14·affinity + 0.10·tempoFit

4. 列表多样性（MMR）：逐首贪心选择， mmr = 0.78·score − 0.22·max sim(候选, 已选)， 相似度取特征 L1 距离并经同歌手/同曲风惩罚，避免整张歌单同质。

5. 情绪弧线排序：疗愈/提振模式下，首曲取与当前情绪最接近的一首（先共情）， 其后按目标契合度递增排列，形成「被理解 → 被带出」的过渡曲线。

6. 反馈学习：喜欢 / 不喜欢 / 跳过会在线更新偏好向量 pref ← pref + η·(f − pref)（ηlike=0.22，ηdislike=−0.20）， 存入 localStorage，下一次推荐即生效。

三、曲库与在线接口

本地曲库：8 首离线 MP3（程序化合成的器乐小品，无版权风险）， 每首自带合成时设定的真实声学参数。

在线接口：iTunes Search API（免密钥、支持跨域，返回 30 秒试听 m4a）为主， Audius 开放 API 为备用；按 7 类情绪各配 2–3 组检索词。

在线曲目特征获取（两段式）：

  • 元数据先验：曲风字典 + 标题/歌手关键词增量（如 lofi→能量↓原声↑、remix→律动↑）
  • 音频实测：WebAudio 解码试听片段，用 FFT 计算 RMS 能量、谱质心（亮度）、 谱通量本体密度（律动）、自相关峰值（BPM）、 Krumhansl-Kessler 调性模板相关（大/小调 → 效价校正）
  • 实测结果按 0.62/0.38 等比例校正元数据估计，界面标记「实测 / 估计」

四、工程与隐私

Vue 3（Composition API）+ HTML5/CSS3/原生 ES Module；视频与摄像头用 Canvas 叠加可视化； 音频用原生 Audio 元素。全部模型权重与曲目均在本机，人脸图像只在内存中处理， 不写入磁盘、不上传网络。

五、已知局限

  • 表情分类对侧脸、强逆光、遮挡敏感，建议正脸、均匀光照。
  • 在线接口的音色描述依赖元数据，实测特征只覆盖能量/速度/律动/调性四类。
  • 情绪→音乐的映射是经验性先验，个体差异大，可用「喜欢/不喜欢」逐步校准。
